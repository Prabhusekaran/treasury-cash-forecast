# Privacy

Treasury Cash Forecast collects no data.

- **What it reads:** only the template file you give the assistant.
- **What it writes:** the result workbook and its audit files, in the assistant's working
  folder. A file you upload is never changed; the plugin works on a copy.
- **What it sends:** nothing. The plugin makes no network calls and has no server.
- **Accounts and credentials:** none. There is nothing to sign in to.
- **Tracking:** none. No analytics, no telemetry, no identifiers.

Your file and the result are handled by the AI assistant you run the plugin in, under
that assistant's own terms and privacy policy. The plugin adds nothing to that.

The one download the assistant may make is two open-source Python libraries,
`statsmodels` and `openpyxl`, from the Python Package Index, if they are not already
installed where it runs code.

Questions: open an issue at https://github.com/Prabhusekaran/treasury-cash-forecast/issues
